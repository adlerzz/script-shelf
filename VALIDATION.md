# Проверка версии 0.1.2

- `npm run check`: ESLint (TS/JS/Svelte), svelte-check с 0 ошибками и предупреждениями, Rollup и 14 тестов прошли.
- Тесты: JSON round trip, переназначение IDs при импорте, циклы и отсутствующие родители, ограничения иконок и вложенности, удаление поддерева, порядок соседей, async/return, повторный запуск без конфликта const, ошибки и результаты, сериализация записей и контроль ревизий.
- `npm run test:ui`: интерфейс на Svelte проверен в headless Chromium с моками Chrome API: создание папок/подпапок/скриптов, сохранение, дублирование, сортировка, PNG-иконка, экспорт файла, добавление и замена при импорте, некорректный JSON, выбор родителя, удаление папки с содержимым, поиск и запуск из popup, nullable-привязка корневой папки, вставка отступа через Tab, сохранение DTO без прокси Svelte, отказ от переключения несохранённого черновика и конфликт ревизий с другим окном.
- Реальное исполнение `chrome.userScripts.execute` в установленном расширении в обычном Chrome в этом окружении не проверялось. Проверены создаваемый код и взаимодействие с API через моки; после установки проверь пример `return document.title;` на обычной веб-странице.

- Сборка очищает `dist`; файлов `.map` и ссылок `sourceMappingURL` нет. Команды `dev`, `zip`, упаковщик релиза и зависимость `fflate` удалены.

- Стили перенесены в scoped `<style>` компонентов. В браузере проверены стили дерева, иконок, редактора, кнопки в snippet шапки, ширина popup и адаптивная раскладка на 500px.

- Lock-файл синхронизирован с 0.1.2; `lint:fix` применён. JSON и сообщения проходят тайпгарды, литеральные поля используют именованные типы и константы. Тесты дополнены проверками неполных сообщений и некорректных результатов выполнения.
- CSS использует вложенные селекторы и `@media`; стили списка папок находятся в `ScriptEditor.svelte`.

- CodeFlask 1.4.1: в браузере проверены токены JavaScript и цвета темы, номера строк, быстрый ввод с сохранением в той же задаче, Ctrl+S, Tab, переключение скриптов и удаление редактора при выборе папки. Страницы проверены с `script-src 'self'` без внешних скриптов.
